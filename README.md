# Welcome to TCA!

- 📖 [Astro docs](https://docs.astro.build)

## Development

Run the dev server:

```shellscript
npm run dev
```

## Deployment

First, build your app for production:

```sh
npm run build
```

Then preview the production build locally:

```sh
npm run preview
```

Make sure to deploy the output of `npm run build` (`dist/`).
